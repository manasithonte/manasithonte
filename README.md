## ⭐ Featured Projects

### 🤖 [Nexus](https://github.com/manasithonte/nexus) – AI-Powered Dependency Upgrade Assistant
Scans GitHub repos for outdated Python and Node.js dependencies, uses Gemini to assess upgrade risk, and opens a pull request with the fixes. Found **114 known vulnerabilities across 17 packages** in a real 54-package project, and runs **2.6x faster** after parallelizing API calls and batching LLM requests.
`Python` `FastAPI` `React` `Gemini` `LLM` `Server-Sent Events`

### 📈 [PulseAI](https://github.com/manasithonte/pulseai) – Real-Time ML Anomaly Detection
Monitors a fleet of 50 servers in real time and flags abnormal ones with ML, scoring each node in **2–3 ms**. Isolation Forest catches every injected anomaly with a **1.8% false positive rate**. Includes Slack and email alerts, a live dashboard, and **28 tests in CI**.
`Python` `FastAPI` `Redis Streams` `PostgreSQL` `scikit-learn` `PyTorch` `React` `Docker`

### 🎬 [slate-parallel](https://github.com/manasithonte/slate-parallel) – Multi-Agent Media Localization *(Hackathon, Oct 2026)*
Four AI agents subtitle, dub, reframe and compliance-check a film trailer, turning one source video into platform-ready versions for every target language.
`Python` `FastAPI` `Gemini` `Vertex AI` `Google Cloud` `FFmpeg`

### 💬 [ChatDB](https://github.com/ManasiThonte1806/ChatDB4) – Natural Language to Database Queries
Converts plain-English questions into SQL and MongoDB queries so non-technical users can explore data.
`Flask` `spaCy` `MongoDB` `SQL`
